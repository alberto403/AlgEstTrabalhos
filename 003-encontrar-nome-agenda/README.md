## Como executar o programa
1. Certifique-se de ter o Python instalado em seu sistema.
2. Clone ou baixe este repositório para o seu computador.
3. Navegue até o diretório do projeto usando o terminal ou prompt de comando.
4. Execute o programa com o comando:
```bash
    python main.py
```
5. Siga as instruções na tela para inserir o nome do contato que deseja encontrar na agenda.

## Como editar a agenda
1. Abra o arquivo `main.py` em um editor de texto ou IDE de sua preferência.
2. Adicione os nomes desejados na lista `agenda` dentro do código, seguindo o formato:
```python
    agenda = ["Nome1", "Nome2", "Nome3"]
```
3. Salve as alterações e execute o programa novamente para testar a nova agenda.
