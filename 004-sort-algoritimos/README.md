# 004 - Sort Algoritimos

Três algoritmos de ordenação implementados em Python.

## Arquivos

| Arquivo | Algoritmo | Melhor caso | Caso médio | Pior caso |
|---|---|---|---|---|
| `bubble_sort.py` | Bubble Sort | O(n) | O(n²) | O(n²) |
| `merge_sort.py` | Merge Sort | O(n log n) | O(n log n) | O(n log n) |
| `insert_sort.py` | Insert Sort | O(n) | O(n²) | O(n²) |

- `main.py` — Executa os três algoritmos e mede o tempo de cada um

## Como usar

```bash
cd 004-sort-algoritimos
python main.py
```

O programa ordena uma lista de 30 nomes e exibe no terminal a lista ordenada e o tempo de execução de cada algoritmo.
